# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc] in full. The
canonical text is at https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: participate respectfully, assume good faith, and accept that people
here have different contexts, languages, and levels of experience — which is
substantially the point of a project about building for people unlike yourself.

## Reporting

Report unacceptable behaviour to **akaguara@gmail.com**. Reports are handled
confidentially and you will get a response within seven days.

The maintainer is currently a single person, which means enforcement is
imperfect and slow by nature. If a report concerns the maintainer, or you would
rather not raise it directly, say so in the report and it will be referred to a
neutral third party.

## A note specific to this project

Disagreement about a rule is not a conduct issue — it is the mechanism by which
this repo improves, and field reports that contradict an existing rule are
explicitly the most welcome contribution here. Dismissing someone's account of
their own market, or their own users, is a conduct issue.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
